# PARATUS

Semper paratus or always prepared will be a productivity tool similar to todoist

This is another attempt at using a monorepo to build both a web and mobile (react native) app in a single workspace sharing trpc, prisma, and other code.

See [paratus-pnpm-mono](https://github.com/fillip1984/paratus-pnpm-mono/tree/main) for my previous attempt at this.
